Glossaryplain-English notes for the terms used on this site

termmeaning
spongeThe hash construction mode: message blocks are absorbed into a state, output bits are squeezed out. SHA3 is a sponge.
sponge-forwardThe mode used by Dragon/Thunder: the capacity part is saved before each permutation call and XORed back afterwards. This lifts preimage security from c/2 to ≈ min{c, h} (ideal-permutation model), so c = h + 64 suffices (a plain sponge needs c ≥ 2h). See ePrint 2025/1006.
permutationAn invertible transformation on a fixed-length bit string; here a multi-round map on the 1600-bit state (Dragon-p: 16 ARX rounds; Thunder-p: 12 Keccak-p-shaped rounds).
capacity (c) / rate (r)The two parts of the sponge state: r bits are absorbed/squeezed per block, c bits are the internal security margin, r + c = 1600. Larger c: more security, slower.
absorb / squeezeAbsorbing: XOR a message block into the state and apply the permutation; squeezing: read output bits out. XOFs squeeze repeatedly.
XOFExtendable-output function: the caller chooses the output length ν (unlike a fixed-length hash digest).
digestThe hash output; Thunder-512 outputs 512 bits.
collision / (second-)preimageThe two classic attack goals: find two messages with the same digest / find a message mapping to a given digest. Design targets: collision ≈ h/2 bits, preimage ≈ h bits.
log₂QThe generic security level of an XOF instance: the bound on the adversary's advantage after Q permutation queries. The 256 in XOF-256 is this level, not an output length.
cpb (cycles/byte)CPU cycles per byte of input — lower is faster. S1–S8 are the self-assessment message lengths 32 B → 64 KiB.
KATKnown-Answer Test: the submission provides “input → expected output” pairs; an implementation passes if it reproduces every answer, showing it matches the specification.
reference / optimized implementationSubmissions ship several tiers: reference is a readable transcription of the spec (slow), optimized targets speed. The two performance tables on this site come from these different tiers (and machines) and are not directly comparable.
constant-timeExecution time and memory addresses do not depend on secret data — a necessary condition against timing side channels.
domain separationMaking internal states for different uses/lengths unconfusable. Both families use distinct IVs per instance, plus the final-block constant C = 0^{c−1}‖1 (which separates the last block from all others and prevents length extension). Between instances sharing a capacity, only the distinct IVs provide separation.
laneThe 1600-bit state is a 5×5 array of 64-bit words; each word is a lane.
ARXModular Addition, Rotation, XOR — the three instruction types that make up Dragon-p.
pd10* paddingThe padding rule: append a single 1 bit, then zeros up to the block boundary (extra all-zero block case: see the specification page).
kGE / TP/AreaHardware metrics: area in thousand gate equivalents; throughput divided by area (higher = more area-efficient).

This table is a reading aid; definitions follow the two specifications and the ngcc.dev notes.
