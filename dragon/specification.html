中文摘要
六个实例共享 1600-bit 状态与同一个 16 轮置换 Dragon-p，差别只在 capacity c、rate r、IV 与输出规则。 注意一个命名陷阱：Dragon-XOF-256/384/512 中的数字是安全等级（log₂Q），不是输出长度； ICCS 一次性 API 观察到的 digest 长度是一个 squeeze block（1280/1152/1024 bit）。

All bit lengths. Message limit 2⁶⁴ bits (§2.7).

XOF naming trap. Dragon-XOF-256/384/512 name a security level (log₂Q, spec Table 6), not an output length. The one-shot API reports one squeeze block — 1280 / 1152 / 1024 bits (160 / 144 / 128 bytes) — so XOF-256 advertises a longer fixed digest than XOF-512. The implementation itself supports arbitrary ν.

Mode: sponge-forward (spec Fig. 1)

An ordinary sponge in which the inner (capacity) part of the pre-permutation state is fed forward and XORed back into the inner part after every permutation call. This raises (second-)preimage security to ≈ min{c, h} instead of the classical c/2, so a 1600-bit state suffices for a 1024-bit preimage target. Padding is pd10*; a domain constant C is XORed into the last block (the lowest bit of lane S[0,0]). The mode and its security analysis are due to Guo, Hu, Jiang, Fan, Fu, Preneel and Wang (ePrint 2025/1006, to appear at CRYPTO 2026).

Sponge-F^{P,pd10*}(M, nu):
    (M[1..L]) <- split_r( pd10*(M) )
    X <- 0^r || IV
    for i = 1..L:                     # absorb
        X <- X XOR (M[i] || (i==L ? C : 0))
        X <- P(X) XOR (0^r || right_c(X))   # the feed-forward
    for i = 1..ceil(nu/r'):           # squeeze
        Z[i] <- right_{r'}(X)
        if i < last: X <- P(X) XOR (0^r || right_c(X))
    return left_nu(Z[1] || ... )

Permutation Dragon-p (spec §2.4)

16 rounds, R_i = φ ∘ ι_i: ι XORs a round constant into S[0,0] (RC_i follows the pattern i·15+15); φ = Col ∘ Diag applies the ARX map Update to five diagonals then five columns of the 5×5 lane array. Update mixes additions mod 2⁶⁴ and rotations by (1, 10, 24, 33, 49) bits.

Update(a,b,c,d,e):                 # + mod 2^64, <<< rotl
    b += e ;  d = (d <<< 33) ^ b
    a += d ;  c = (c <<< 24) ^ a
    e += c ;  b = (b <<< 10) ^ e
    d += b ;  a = (a <<< 1)  ^ d
    c += a ;  e = (e <<< 49) ^ c
