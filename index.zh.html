Dragon 与 ThunderNGCC Round-1 杂凑候选算法 — 设计团队资料站

Dragon（候选编号 hash-07）与 Thunder（hash-33）是本组设计、提交至中国 Next Generation Commercial Cryptographic (NGCC) algorithms program Round 1 的两个 hash 候选。本站由设计团队维护： 每个候选一套页面（规范 / 实现 / 性能 / 分析），第三方分析取自 ngcc.dev，原始材料为我们的 NICCS 官方提交包， 全部数字已对照提交 spec 的 LaTeX 源逐格核验。

Dragon 杂凑家族

hash-07 · permutation-based（ARX）

1600-bit 状态，16 轮 Dragon-p，sponge-forward 模式。六个实例：Dragon-512/768/1024 与 Dragon-XOF-256/384/512。x86-64 长消息 4.87 cycles/byte（本组自评估，spec Table 14）。

Thunder 杂凑家族

hash-33 · permutation-based

1600-bit 状态，12 轮 Thunder-p（三次非线性层 ψ），sponge-forward 模式。六个实例：Thunder-512/768/1024 与 Thunder-XOF-256/384/512。x86-64 长消息 6.95 cycles/byte（本组自评估，spec Table 18）。
