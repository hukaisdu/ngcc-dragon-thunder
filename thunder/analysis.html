Security status

No vulnerability finding is currently published for this candidate (ngcc.dev security report, snapshot 2026-10-28). This records only the present state of the public finding inventory and is not a security endorsement; the candidate remains under review.

Constant-time audit (ngcc.dev)

Scope: archived reference implementation, fixed digest parameters and fixed message length; message contents and intermediate state treated as secret. Two source points examined:

  • Reference entry: Thunder-ARM/…/Reference_Implementation/Thunder-1024/CryptHash_AlgorithmInstance.c:175.
  • The XOF output-bit copy has if (src_bit) (Thunder-X86/…/Thunder-XOF-256/CryptHash_AlgorithmInstance.c:187). GCC -O2 compiles this to a cmovne with fixed-address accesses, so it is not a compiled branch in the reviewed build — other compilers and targets still require checking.

Status: no issue promoted for the reviewed GCC build. Full text: mirrored audit page · live.

Implementation-vs-specification review

No parameter or constant mismatch found. The whole permutation was checked entry by entry; capacities, rates, IV placement (reverse-order array with compensating loader), feed-forward, message layout, padding and the final-block constant all match the spec.

Output-length domain separation — verified (ngcc.dev)

  • Distinct IVs per instance (spec Table 6) — all six load completely different IV lane sets, including the pairs that share a capacity (512/XOF-256, 768/XOF-384, 1024/XOF-512).
  • Distinct rate/capacity split per security level (576/832/1088).
  • Final-block constant C = 0^{c−1}‖1 — also the length-extension defence, which matters more than usual because the digest is read from the inner part.

Caveat inherent to XOFs: within one instance, outputs of different lengths are prefixes of one another; the three harness-exposed fixed lengths (1280/1152/1024 bits) are not separate hash functions.

Notes worth remembering

  • IV constants (spec Table 6) have no published derivation rule — a transparency gap worth noting, not a break.
  • ψ has algebraic degree 3 (Keccak’s χ has degree 2) and θ uses two column parities — relevant when setting up trail/differential search.
  • Related: “Chinese NGCC Algorithms: The First Week of AI Cryptanalysis”, IACR ePrint 2026/2266.
