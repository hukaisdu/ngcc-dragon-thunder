Performanceindependent cycle counts — reference implementation

中文摘要
下表是 ngcc.dev 在 x86_1（i7-12700，单核定频 2.1 GHz，gcc 14.2 -O2，Debian 13）上对 reference 实现的独立测量（先过 KAT 再计时）。Thunder-512 长消息约 32.4 cycles/byte（64.6 MB/s）， 约为同场景 Dragon-512（17.8 cycles/byte）的 1.8 倍耗时；完整表与 arm_1 数据见链接。

For comparison, on the same machine and campaign, Dragon-512 measures 17.8 cycles/byte at 64 KiB (Dragon performance). The large 32 B figures for the XOF instances reflect the one-squeeze fixed digest (160/144/128 bytes) counted over a tiny message.
