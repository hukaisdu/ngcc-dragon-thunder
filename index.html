Dragon & ThunderNGCC Round-1 cryptographic hash candidates — study pages

中文摘要
Dragon（候选编号 hash-07）与 Thunder（hash-33）是中国 Next Generation Commercial Cryptographic (NGCC) algorithms program Round 1 的两个 hash 候选。本站为研究用资料镜像与导读： 每个候选一套页面（规范 / 实现 / 性能 / 分析），素材取自 ngcc.dev 的独立分析与 NICCS 官方提交包， 镜像日期 2026-10-30。

Dragon Hash Family

hash-07 · permutation-based (ARX)

1600-bit state, 16-round Dragon-p, sponge-forward mode. Six instances: Dragon-512/768/1024 and Dragon-XOF-256/384/512. ≈17.8 cycles/byte (Dragon-512, 64 KiB, x86_1).

Thunder Hash Family

hash-33 · permutation-based

1600-bit state, 12-round Thunder-p with degree-3 nonlinearity, sponge-forward mode. Six instances: Thunder-512/768/1024 and Thunder-XOF-256/384/512. ≈32.4 cycles/byte (Thunder-512, 64 KiB, x86_1).

What is in this repository

  • dragon/, thunder/ — these study pages (static HTML, one shared stylesheet).
  • harness/ — snapshot of the ngcc-harness repository at dc66c6cb: specification PDFs, algorithm summaries, constant-time notes, KAT manifests and the full extracted submission trees (hash-07/, hash-33/), plus the top-level build files.
  • ngcc-site/ — offline copy of the ngcc.dev pages for both candidates (security reports, constant-time audits, x86_1 / arm_1 performance details and the measurement method).
  • official-archives/ — the official NICCS Round-1 submission packages (each ≈140 MB, above GitHub's 100 MB per-file limit, so fetched by fetch-archives.sh and checked against SHA256SUMS.txt).
