Dragon & ThunderNGCC Round-1 cryptographic hash candidates — the design team's site

Dragon (hash-07) and Thunder (hash-33) are two hash candidates we designed and submitted to the Chinese Next Generation Commercial Cryptographic (NGCC) algorithms program, Round 1. This site is maintained by the design team: one page set per candidate (specification / implementations / performance / analysis), with independent third-party analysis from ngcc.dev and all performance figures re-verified cell-by-cell against the LaTeX source of our submitted specifications.

Dragon Hash Family

hash-07 · permutation-based (ARX)

1600-bit state, 16-round Dragon-p, sponge-forward mode. Six instances: Dragon-512/768/1024 and Dragon-XOF-256/384/512. 4.87 cycles/byte at 64 KiB on x86-64 (our self-assessment, spec Table 14).

Thunder Hash Family

hash-33 · permutation-based

1600-bit state, 12-round Thunder-p with degree-3 nonlinearity, sponge-forward mode. Six instances: Thunder-512/768/1024 and Thunder-XOF-256/384/512. 6.95 cycles/byte at 64 KiB on x86-64 (our self-assessment, spec Table 18).

What is in this repository

  • dragon/, thunder/ — these study pages (static HTML, one shared stylesheet).
  • harness/ — snapshot of the ngcc-harness repository at dc66c6cb: specification PDFs, algorithm summaries, constant-time notes, KAT manifests and the full extracted submission trees (hash-07/, hash-33/), plus the top-level build files.
  • ngcc-site/ — offline copy of the ngcc.dev pages for both candidates (security reports, constant-time audits, x86_1 / arm_1 performance details and the measurement method).
  • official-archives/ — the official NICCS Round-1 submission packages (each ≈140 MB, above GitHub's 100 MB per-file limit, so fetched by fetch-archives.sh and checked against SHA256SUMS.txt).
